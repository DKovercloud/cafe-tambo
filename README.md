# Café Tambo

Página web de una cafetería, hecha para practicar diseño web: estructura clara, estilo propio y adaptación a distintos tamaños de pantalla.

🔗 **Demo en vivo:** https://github.com/DKovercloud/cafe-tambo.git

## Qué incluye

- [Sección de inicio con presentación de la cafetería]
- [Menú de productos]
- [Datos de contacto y ubicación]

## Tecnologías

- HTML5
- CSS3
- [JavaScript, si lo usaste]

## Cómo verla en tu computadora

1. Descarga o clona el repositorio:
   ```
   git clone https://github.com/DKovercloud/cafe-tambo.git
   ```
2. Abre el archivo `index.html` en tu navegador.
